## Design Priority

AgentMS is an agent-first student accommodation product. The design must make current room availability, agent trust, listing freshness, and inquiry follow-up easier to understand and manage.

Creative direction is allowed only where it strengthens those priorities. Decorative choices must stay quiet, operational, and scan-friendly.

## MVP Boundaries

Included:

- Student discovery and inquiry flow.
- Agent profile, verification, listing management, availability refresh, and inquiry follow-up.
- Admin trust review, moderation, location management, and baseline platform monitoring.
- Email verification, inquiry, stale listing, and verification result notifications.

Excluded:

- Direct booking.
- Payments, deposits, wallets, marketplace stores, and delivery.
- Full hostel manager or tenant management.
- In-app chat, native mobile apps, AI recommendations, and advanced analytics.
