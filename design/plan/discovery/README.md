# Discovery Notes Design Alignment

The design reflects the pivot from manager-centered hostel management to agent-centered availability operations.

Previous-system concepts that should not dominate MVP design:

- Tenant management.
- Reservation/payment flow.
- Marketplace.
- Dynamic admin database editing.

Useful retained concepts:

- Campus/location fixtures.
- Hostel/listing search.
- Gender and price filters.
- Reviews and trust signals, reframed around listing and agent reliability.
