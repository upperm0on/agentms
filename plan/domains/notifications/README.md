# Notifications

This domain owns transactional emails and future SMS/WhatsApp notification hooks.

Previous system behavior:

- Email verification
- Reservation confirmation
- Payment confirmation
- Reservation reminders
- Login alerts
- Maintenance notifications
- Daily summaries
- Occupancy reports
- Admin/manager action notifications

AgentMS direction:

- Keep transactional notifications, but scope them tightly.
- Email/SMS/WhatsApp should support agent workflows and student inquiries.

MVP notifications:

- Email verification
- New inquiry notification to agent
- Inquiry confirmation to student
- Stale listing reminder to agent
- Admin verification result

Future notifications:

- Viewing reminders
- Deposit/payment receipts
- Weekly agent performance summary
- Student saved-search alerts
