# Inquiry Workflow

Student actions:

- Submit inquiry from listing detail.
- Provide message.
- Provide or confirm phone number.
- Choose preferred contact method.
- View own inquiries if authenticated.

Agent actions:

- View inquiries for own listings.
- Update status.
- Add private notes.
- Mark invalid or spam.

Admin actions:

- Inspect inquiry records when needed for moderation or support.

Future reservation states:

- Requested
- Agent Accepted
- Deposit Pending
- Deposit Paid
- Room Held
- Converted
- Expired
- Cancelled
