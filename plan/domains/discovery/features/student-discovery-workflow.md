# Student Discovery Workflow

Workflow:

1. Student visits listing browse page.
2. Student selects campus or area.
3. Student filters by price, gender, room type, availability, and freshness.
4. Student opens listing detail.
5. Student checks agent trust information.
6. Student submits inquiry or contacts agent.
7. Inquiry is recorded.
8. Agent receives notification.

MVP pages:

- Public listings page
- Listing detail page
- Agent public profile page
