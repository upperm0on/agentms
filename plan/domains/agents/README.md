# Agents

This domain owns agent profiles, verification, operating areas, public trust metadata, and agent dashboard identity.

MVP features:

- Create profile
- Update profile
- Phone and WhatsApp contact
- Operating campuses/areas
- Verification status
- Profile photo or business logo

Agent verification states:

- Unsubmitted
- Pending
- Verified
- Rejected
- Suspended

Agent trust indicators:

- Verification badge
- Response rate
- Listing freshness score
- Report history
