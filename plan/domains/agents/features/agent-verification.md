# Agent Verification

Purpose:

- Increase student trust.
- Reduce fake listings.
- Give admins a clear onboarding review queue.

Verification request fields:

- Agent
- ID document
- Selfie or profile photo
- Supporting notes
- Status
- Reviewed by
- Reviewed at
- Created at

Admin actions:

- Approve
- Reject with reason
- Suspend
- Reopen review

Rules:

- Agents cannot approve their own verification.
- Verification decisions should be audit logged.
- Rejected agents may update documents and resubmit unless suspended.
