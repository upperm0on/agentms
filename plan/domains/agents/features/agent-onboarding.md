# Agent Onboarding

Workflow:

1. Agent signs up.
2. Agent verifies email.
3. Agent completes profile.
4. Agent adds operating campuses/areas.
5. Agent submits verification documents.
6. Admin reviews verification.
7. Agent can create draft listings immediately.
8. Only approved listings appear publicly.
9. Verified agents receive visible trust indicators.

Open product decision:

- Decide whether unverified agents can publish listings, or whether publishing requires admin approval.
