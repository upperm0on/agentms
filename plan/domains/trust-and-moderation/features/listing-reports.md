# Listing Reports

Purpose:

- Let students and admins flag bad listing data.

Report reasons:

- Stale
- Fake
- Wrong price
- Wrong location
- Duplicate
- Abusive agent
- Other

Report statuses:

- Open
- Reviewing
- Resolved
- Dismissed

Rules:

- Reported listings reduce listing visibility until reviewed.
- Admin actions should be audit logged.
- Repeat reports should affect agent trust score.
