# Listing Media

Purpose:

- Help students inspect rooms before contacting agents.
- Improve trust and reduce misleading listings.

MVP features:

- Upload listing images.
- Set cover image.
- Delete image.
- Add optional caption.
- Sort images.

Rules:

- Published listings should have at least one image unless explicitly allowed by admin policy.
- Uploaded media must be validated.
- Image storage must use new environment-backed credentials when remote storage is introduced.
