# Testing Strategy

## Backend Tests

- Account registration/login
- Role permissions
- Agent profile creation/update
- Agent verification submission
- Listing CRUD
- Listing publish/unpublish
- Availability refresh
- Student inquiry creation
- Agent inquiry status update
- Admin moderation
- Report flow

## Frontend Tests

- Public listing browsing
- Listing filters
- Listing detail inquiry flow
- Agent listing create/edit form
- Agent dashboard states
- Admin moderation states

## Manual QA Scenarios

- New agent creates first listing.
- Student finds a fresh listing and sends inquiry.
- Agent updates inquiry to viewing scheduled.
- Agent marks listing full.
- Admin rejects a fake listing.
- Stale listing reminder triggers.
