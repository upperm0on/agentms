# Permissions Matrix

## Student

- Can browse published listings.
- Can create inquiries.
- Can view own inquiries.
- Can report listings.
- Cannot create public listings.
- Cannot moderate agents or listings.

## Agent

- Can manage own profile.
- Can create own listings.
- Can update own listings.
- Can delete/archive own listings.
- Can view inquiries for own listings.
- Can update own inquiry statuses.
- Cannot edit another agent's listings.
- Cannot approve own verification.
- Cannot access admin dashboards.

## Admin

- Can view all users, agents, listings, inquiries, and reports.
- Can verify/suspend agents.
- Can approve/hide/remove listings.
- Can manage locations.
- Can view analytics.
- Should not impersonate users unless an explicit audited support feature is later approved.

## Anonymous

- Can browse public listings.
- Can view public listing details.
- May be required to sign up before sending inquiry, depending on final requirements.
