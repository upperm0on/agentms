# Phase 4: Verification And Testing

Objective:

- Prove the system works against requirements.

Deliverables:

- Unit tests
- API tests
- Integration tests
- Frontend route tests
- Manual QA checklist
- Security checklist
- Seed data
- Bug log

Exit criteria:

- MVP acceptance criteria pass.
- Critical and high bugs are closed.
- Test data covers multiple campuses, agents, listings, and inquiry states.
