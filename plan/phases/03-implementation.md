# Phase 3: Implementation

Objective:

- Build the approved design in controlled modules.

Implementation order:

1. Backend project foundation
2. Auth and roles
3. Agent profile module
4. Location module
5. Property/listing module
6. Media upload module
7. Inquiry module
8. Admin moderation module
9. Notification module
10. Frontend foundation
11. Agent dashboard
12. Student discovery
13. Admin dashboard

Exit criteria:

- Each module has tests.
- Each module matches the approved API specification.
- Frontend screens consume real backend APIs or documented mocks only.
