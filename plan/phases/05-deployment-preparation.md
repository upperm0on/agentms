# Phase 5: Deployment Preparation

Objective:

- Prepare production-safe release.

Deliverables:

- Environment variable checklist
- New secret/key setup
- Database migration checklist
- Hosting configuration
- Static/media storage setup
- Domain/CORS/CSRF configuration
- Backup and rollback plan
- Admin bootstrap process

Exit criteria:

- No old credentials from `prev/` are reused.
- Production settings are separated from development settings.
- Deployment can be repeated from documented steps.

- [Environment And Secrets](../deployment/environment-and-secrets.md)
- [Non-Functional Requirements](../requirements/non-functional-requirements.md)
